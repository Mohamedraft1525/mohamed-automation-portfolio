# Mohamed Raafat — Automation & RPA Portfolio

A one-page React + Vite portfolio website focused on real automation, RPA, n8n, and data workflow projects.

## Run locally

```bash
npm install
npm run dev
```

## Add profile image

Put your image in:

```text
public/profile.jpg
```

## Build

```bash
npm run build
```

## Deploy

Upload the project to GitHub, then import the repository on Vercel.

Build command: `npm run build`
Output directory: `dist`
